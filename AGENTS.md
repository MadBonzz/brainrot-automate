# Making an episode in a Codex terminal session

Take the user's premise through to a playable vertical MP4. Use the requested length, or about 45 seconds by default. The standard episode contract lives in `film/ensemble.py`. Both `example/floor-ten/` and `example/bell-bay/` contain complete plans.

1. Write a first-person story around an observable rule. Show how people have adapted their jobs, family lives or customs to it. Give at least four residents distinct interests. Let the audience see the ordinary approach fail, discover a counterexample and understand what the protagonist stands to lose. End with a visible consequence and a joke or image that pays off an earlier detail.
2. Make a unique folder under `plans/`. Write `story.json` and `direction.json` using the ensemble schemas. Invent landmarks and practical props for this particular town. Keep positions and ownership consistent. Give actors independent tasks, eyelines and gesture windows. Put the evidence in its own shot when a wide view would hide it. Use spoken phrase anchors for reveals. List reusable performances with `python movie.py --list-actions`. Review a new authored pose with `tools/review_motions.py`.
3. Render the boards with `python movie.py --from-plan <folder> --quality review --storyboard`. Inspect the numbered pages inside the printed storyboard folder. Check whether a viewer can follow the public example, failed attempt, exception, cost and ending from the images. Correct unclear blocking, framing or impossible prop contacts in the job's direction.
4. Run `python movie.py --resume <job-folder> --quality final` or use the user's requested review quality. The runner uses the local narrator, Blender and FFmpeg and measures the rendered frame sequence. Report the playable file and measured duration.

An outer Codex session can write the plans directly. The standalone Python entry point calls the configured Codex CLI for a draft, an editorial review, the world and short blocks of direction. For a JSON-only request with an output schema, respond with that JSON.
